# IT Outsourcing Company — Corporate Website

Corporate website for an IT outsourcing company specializing in
banking/fintech software development (credit & microfinance systems,
BNPL/installment platforms, fintech backend, KYC/compliance, outstaffing,
CRM/ERP), built from the project's technical specification (TZ).

## Project

The Angular application lives in [`it-outsourcing-site/`](./it-outsourcing-site).
See that folder's [README](./it-outsourcing-site/README.md) for the stack,
pages, and instructions to run, build, and test it.

**Quick start:**

```bash
cd it-outsourcing-site
npm install
ng serve
```

Then open `http://localhost:4200/`.
